    Google Maps configuration required

    Add your Google Maps API key near the top of index.html.

    const GOOGLE_MAPS_API_KEY = "PASTE_YOUR_KEY_HERE";

    Enable Maps JavaScript API, Places API (New), and Elevation API on that key. Billing must be active. Serve this file over localhost — Google Maps will not load from a file:// URL.

    python3 -m http.server 8000

    Or paste a key to launch this session:

    Get a key: https://developers.google.com/maps/documentation/javascript/get-api-key
