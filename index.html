    DATA & IMAGERY SOURCES

    Map data © OpenStreetMap contributors (ODbL).

    Open Earth: Esri World Imagery (Maxar / Earthstar) + OSM raster fallback. Vector streets: OpenFreeMap when reachable.

    Terrain: AWS Terrain Tiles (Terrarium / Mapzen DEM) when available.

    Street imagery: Mapillary (optional token) → KartaView → Wikimedia Commons → Panoramax.

    Search: Open-Meteo Geocoding + Photon. Google Geocoder if you pasted a Maps key.

    Buildings: Overpass API. Walk-mode 3D uses PBR + rasterized shadows — not photoreal tiles.

    Optional Google Earth uses your Maps JavaScript key in this browser only.
